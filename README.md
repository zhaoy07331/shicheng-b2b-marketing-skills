# 事橙营销 · B2B Marketing Skills

来自事橙实际官网工作的专业规则Skill。官网文章解释方法，Skill提供输入、合格标准、验收证据、缺项处理与输出，Agent按具体任务使用。

本仓库仅公开专业判断和审校规则，不包含部署脚本、账号配置、自动发布、广告操作、系统写入或监控执行能力。

## 当前维护的三个官网Skill

| Skill | 版本 | 具体标准 |
| --- | --- | --- |
| [网站GEO友好性优化](skills/website-geo-review/SKILL.md) | 1.1.0 | 技术访问、网站架构、答案内容、可信信息、持续运营，五方向20项标准 |
| [官网文章发布协同和自检](skills/website-article-release-review/SKILL.md) | 1.1.0 | 选题正文、页面资产、技术发现、站内协同、发布验收、通知归档与后续运营，六阶段24项标准 |
| [B2B网站改版善后Skill](skills/b2b-website-relaunch-aftercare/SKILL.md) | 1.0.0 | 改版范围、网址与301、索引信号、内容附件、咨询与数据、公网交付、搜索通知、后续维护，八方面32项标准 |

三项统一“官网”标签，保留稳定ID和公开网址。每项标准分别给出应达到的状态、需要的实际证据和不合格时的处理；资料足够时给可审阅的TDK、段落、Schema字段、Sitemap条目、内链或URL映射修订草案。条件不适用时说明原因，不机械新增FAQ、案例、Skill或Agent，不设置固定关键词密度。

## 使用

[官网Skill-Store](https://www.shichengup.com/skill-store/)提供详情、复制提示与下载。将详情URL或某个SKILL.md的GitHub/Raw地址交给能读取网页的AI，请它结合你的资料按规则审校。支持持久Skill的Agent可由用户确认后保存目录；普通聊天工具可在当前对话参考。能否读取、安装、保存和跨对话调用取决于工具能力，本仓库不承诺自动安装。

首次使用请说明任务、网址或材料、真实业务资料、资料日期、读取范围与公开边界。Skill不能补造产品能力、价格、案例、效果或权限；对无法获得的响应、部署、搜索后台及AI原始回答，应保留未验证。建议和已执行结果分别记录。

## 与官网、文章及Agent的关系

[官网GEO指南](https://www.shichengup.com/insights/blog/geo-friendly-website-optimization/)与其他明确关联文章提供学习背景。文章开头和底部提供配套入口，详情反向关联文章；catalog.json保存ID、版本、工作角色、来源文章和全部标准。网页与自包含SKILL.md使用同版完整规则，不把关键标准藏在额外本地依赖里。B2B网站改版善后Skill关联官网正式目录中的[官网运营Agent](https://www.shichengup.com/ai-lab/marketing-ai-agent/website/)与[SEO运营Agent](https://www.shichengup.com/ai-lab/marketing-ai-agent/seo/)；具体工具能力与操作授权按任务另行确认。
