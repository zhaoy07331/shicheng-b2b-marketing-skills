# 事橙营销 · B2B Marketing Skills

可阅读、可下载、可按项目调整的B2B营销专业规则。每个目录包含独立的 `SKILL.md`，采用 Agent Skills 的名称、描述和正文组织方式。中文说明便于营销团队理解，英文稳定ID便于工具识别。

本仓库只保存专业知识、诊断与审校规则；不包含脚本、账号配置、自动发布、投放操作或业务系统写入能力。

## 当前维护的两个官网Skill

| Skill | 用途 |
| --- | --- |
| [网站GEO友好性优化](skills/website-geo-review/SKILL.md) | 五个方向检查官网与证据缺口 |
| [官网文章发布自检](skills/website-article-release-review/SKILL.md) | 核对关键词、内链、作者、Schema、Sitemap与真实上线回执 |

两个Skill都带“官网”标签。网站GEO友好性优化用于网站诊断，官网文章发布自检用于发布前后审校；自检规则来自事橙实际官网建设、发布与复查工作。其他首批条目已从当前目录移出，历史版本保留在Git记录与v1.0.0中。

## 使用

把某个 `SKILL.md` 的GitHub地址或Raw地址交给能读取网络内容的AI，请它结合你提供的资料应用规则。支持持久Skill的Agent可由用户将目录加入相应技能目录；不同工具的安装方式、存储位置与调用能力不同，本仓库不承诺自动安装。普通聊天工具可在当前对话参考规则。

建议首次使用时明确：业务任务、可用资料、读取范围、资料版本和期望输出。没有提供的产品能力、案例、价格、效果与权限，不能由Skill推测补齐。

## 与官网、文章和Agent的关系

官网文章解释背景和方法，Skill保留可复用专业规则，Agent按照任务选择Skill。`catalog.json`保存稳定ID、版本、来源文章和可服务的工作角色。[官网Skill-Store](https://www.shichengup.com/skill-store/)与[官网GEO-Friendly指南](https://www.shichengup.com/insights/blog/geo-friendly-website-optimization/)已于2026年11月4日上线；GitHub中的SKILL.md也可以独立使用。

## 版本与维护

当前目录版本为1.1.0，其中网站GEO友好性优化为1.0.1，官网文章发布自检为1.0.0。每项Skill保留版本与更新时间；平台相关事实需使用时核对官方资料。变更通过Git记录，发布版本通过GitHub Release冻结。仓库是Skill文本的公开版本来源；官网引用同版文件，不创建另一个不一致的规则分支。

欢迎通过Issue提出缺失条件、错误或适用性反馈。请勿提交客户原件、个人信息、密钥、账号或未经许可的数据。专业规则改进需同时核对来源文章与目录关联。
